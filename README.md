# Syed Anas Faaiz - Software Engineer Portfolio

A premium, modern portfolio website built with **Next.js**, **Tailwind CSS**, and **Framer Motion**. This project showcases my work, engineering expertise, and creative design philosophy.

![Portfolio Preview](https://github.com/AnasFaaiz/Portfolio/raw/main/public/preview.png) *(Note: Placeholder image URL, ensure you have a preview image in your public folder)*

## ✨ Key Features

- **🚀 Performance First**: Built using **Next.js 16** with **Turbopack** for lightning-fast development and optimized production builds.
- **🎨 Premium Aesthetics**: A sleek, dark-themed design (with light mode support) featuring:
  - Glassmorphism effects with `backdrop-blur`.
  - Soft decorative glows and gradients.
  - Custom-weighted typography for a high-end feel.
- **📱 Responsive by Design**: Fully fluid layouts optimized for everything from ultra-wide monitors to mobile devices.
- **🛠️ Project Showcase**: Dedicated `/Projects` page that dynamically fetches repository data from the **GitHub API**.
- **📜 Certifications Hub**: A polished gallery of professional achievements in the `/Certifications` section.
- **✨ Interactive Animations**: Engaging micro-interactions and scroll-based reveals powered by **Framer Motion**.
- **🌓 Dark / Light Mode**: Seamless theme switching using `next-themes`.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Theming**: [next-themes](https://github.com/pacocoursey/next-themes)
- **API**: [GitHub API](https://docs.github.com/en/rest)

## 🚀 Getting Started

### Prerequisites

- **Node.js**: Version 18.x or higher
- **npm** or **pnpm** (preferred)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AnasFaaiz/Portfolio.git
   cd Portfolio/portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Visit the site**:
   Open [http://localhost:3000](http://localhost:3000) in your browser.
