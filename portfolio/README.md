# Syed Anas Faaiz Portfolio (Next.js App)

This is the Next.js frontend for the **Syed Anas Faaiz Portfolio**. It uses a modern, high-performance stack for a premium digital experience.

## 🚀 Quick Run

1. `npm install`
2. `npm run dev`

## 🛠️ Stack

- **Framework**: Next.js 16 (Turbopack)
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **CMS**: next-mdx-remote (v6)

For full documentation, see the [main README](../../README.md) in the project root.
